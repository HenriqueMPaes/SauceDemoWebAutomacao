# Sauce Demo Web Automation

Projeto de automação de testes web desenvolvido com **Playwright** e **TypeScript**, com foco na validação dos principais fluxos da aplicação de demonstração **Sauce Demo**.

O projeto foi estruturado seguindo boas práticas de automação de testes, utilizando **Page Object Model (POM)**, organização por responsabilidades e execução de testes com o Playwright Test.

## 🚀 Tecnologias

- [Playwright](https://playwright.dev/)
- TypeScript
- Node.js
- Playwright Test

## 🧪 Cenários automatizados

### 🔐 Autenticação

- Login com credenciais válidas
- Validação de credenciais inválidas
- Validação de usuário bloqueado

### 🛍️ Produtos

- Visualização do catálogo de produtos
- Ordenação de produtos por menor preço

### 🛒 Carrinho

- Adição de produtos ao carrinho
- Remoção de produtos do carrinho
- Validação dos itens adicionados

### 💳 Checkout

- Validação de campos obrigatórios
- Preenchimento dos dados de checkout
- Conclusão da compra simulada

## 📁 Estrutura do projeto

```text
src/
└── web/
    ├── flows/             Jornadas reutilizáveis
    ├── pages/             Page Objects
    └── support/           Massas e dados de teste

tests/
└── web/                   Especificações dos testes

playwright.config.ts       Configuração do Playwright
tsconfig.json              Configuração do TypeScript
```

## ⚙️ Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

- Node.js 18 ou superior
- npm

## 🔧 Instalação

Clone o repositório:

```bash
git clone https://github.com/HenriqueMPaes/SauceDemoWebAutomacao.git
```

Acesse o diretório do projeto:

```bash
cd SauceDemoWebAutomacao
```

Instale as dependências:

```bash
npm install
```

Instale o navegador Chromium do Playwright:

```bash
npx playwright install chromium
```

## ▶️ Execução dos testes

Executar todos os testes:

```bash
npm test
```

Executar os testes em modo headed:

```bash
npm run test:headed
```

Executar os testes em modo UI:

```bash
npm run test:ui
```

Executar os testes de smoke:

```bash
npm run test:smoke
```

Executar os testes de regressão:

```bash
npm run test:regression
```

## 📊 Relatórios

Para gerar e abrir o relatório de testes:

```bash
npm run report
```

O projeto utiliza os recursos de relatório do Playwright para facilitar a análise dos resultados das execuções.

## 🧹 Qualidade de código

Executar o lint:

```bash
npm run lint
```

Corrigir problemas de lint automaticamente:

```bash
npm run lint:fix
```

Formatar o código:

```bash
npm run format
```

## 🎯 Objetivo

Este projeto foi desenvolvido como parte do meu portfólio de **QA e Automação de Testes**, com o objetivo de demonstrar a aplicação de boas práticas na criação e manutenção de testes automatizados web utilizando **Playwright e TypeScript**.
